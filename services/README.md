# Executive Brain Operator (EBO)

The Executive Brain Operator is the central intelligence of MBO.

Responsibilities

- Receive requests
- Build context
- Retrieve memories
- Select AI provider
- Execute missions
- Return responses

EBO never performs work directly.

It coordinates every subsystem.

# Provider Router

The Provider Router decides which AI model should execute a request.

Goals

- Support unlimited providers
- Automatic failover
- Cost optimization
- Speed optimization
- Local-first when possible

The Executive Brain never talks directly to AI providers.
Everything goes through this router.
